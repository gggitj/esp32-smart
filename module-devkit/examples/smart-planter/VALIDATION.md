# 智能盆栽模块 3.0.0 验证记录

本次仅更新模块应用与模块插件，不修改控制桥、Pi 主程序、Pi profile 或发布公钥；通过终端已有权限弹窗选择“仅本次信任”。

## 实际通过

- SDK `init` 生成示例，`validate` 校验源码工程。
- PC 使用 Pi Qt 6.4.2 sysroot 交叉编译 ARM64 插件。
- SDK `stage` 收集全部 QML 及动态库，文件哈希与实际签名/加载包一致。
- SDK 配包器在 Pi 使用既有私钥签名，公钥验签、完整解压、哈希和架构检查通过；私钥未离开 Pi。
- 原生测试在 PC 和 Pi 运行：历史原子保存、重读、空缺、保留期限、无效值、插件同步停止及低压策略。
- QML 语法检查、Qt 6.4.2 离屏测试：日/周模拟曲线、窄屏布局；模拟数据只用于测试。
- ESP-IDF 5.5.4 构建 LAN 固件，最终应用大小0x127580，原0x177000应用分区可容纳。
- 确认模块序列号 `5CF8047843`，ESP32-S3 / 16MB，备份原应用及NVS覆盖区，分区比对一致，仅写0x10000应用。
- 实机完成 LinkIt / Pi LAN / 认证会话 / 包下载验签 / 插件加载；Pi实际映射库与交叉编译产物 SHA256 一致。
- Pi真实桌面显示植物图示、真实温湿度/气压/照度、45%左右电量及约3.82V（随运行变化）。
- 实际点击日/周按钮，滚动查看电量卡片；历史文件已记录多分钟真实样本。
- 最后一次模块重刷后原业务会话恢复，Pi终端服务未由本次操作重启。

## 不可混同为通过的项目

后续LCD改版：正式ESP工程新增纯黑、简体中文、Noto Sans CJK SC与Roboto、灰阶抗锯齿及唯一RGB565字节序转换，并同步SDK副本。逐字字形覆盖、像素/边界测试和固件编译通过；中文固件已烧录，串口确认LCD任务启动。前一轮颜色修复固件曾确认Pi链路恢复，该结果不替代中文版本的完整回归。实际LCD颜色与中文观感仍需现场目视确认，LVGL预览不当作实屏照片。初次3.0.0应用大小等数值只对应上面的原始验收构建，当前镜像哈希以本机artifacts/validation.json为准。

- 没有真实运行满24小时/7天；目前曲线短是正常，不能造出一周假历史。日/周聚合与文件重读已经用隔离测试验证。
- 未确认/接线 PG/VBUS 信号，因此实际供电来源为 unknown；不会冒充自动识别USB。默认不启用来源未知下的自动低压休眠，必须有电池保护硬件兜底。
- 真实电池放电触发、外部供电插拔策略、自动断电控制器、大开关尚无物理验收。软件测试不代表这些硬件已安装。
- 没有土壤传感器、浇水执行器；不是可直接灌溉的产品。
- Pi桌面当前为labwc/Wayland，实际画面用Wayland捕获；离屏测试不等于硬件图形性能或触摸耐久验收。
- 主程序既有GlassSurface警告不在此次模块开发范围内，不声称整个终端日志无警告。
