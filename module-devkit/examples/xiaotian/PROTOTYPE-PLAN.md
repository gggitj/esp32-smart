# 啸天：首轮原型执行清单

日期：2026-10-25。

状态：设计与准备阶段，尚未采购、接线、烧录或完成实物测试。产品名已更新为“啸天”。本文用于组内分工；完整需求与 GitHub 参考见同目录 [需求与交接说明](DEVELOPMENT-NOTES.md)。桌面副本是导出快照，不与工作区自动同步。

## 1. 本轮交付

用两对主动红外探头和一块现有 ESP32，验证单线告警、双线通行和折线分段告警。立柱为可选附件，先利用稳定的门框、支架或其他固定位置。

本轮采用同一块控制板采集两路信号，作为降低时间同步难度的原型方案。各探头是否最终独立供电、无线回传仍未确定；集中接线原型不代表最终产品必须如此安装。

10×10 m 和闭合区域仍是后续场景目标。两对普通探头不能覆盖四边全开放的矩形；验证后按边数扩展相应的独立光路。

## 3. 探头选型先核实这些参数

新增了速度估算目标，不能只按“会报警、带继电器”选型。

| 关键参数 | 需要取得的答案 | 影响 |
| --- | --- | --- |
| 发射 / 接收端电压和最大电流 | 两端分别记录 | 供电与线径 |
| 输出类型 | 无源干接点、NPN / PNP 或带电数字输出；正常 / 遮挡 / 断电的状态 | 输入接口设计 |
| 遮挡判定与输出延迟 | 最小遮挡时间、滤波 / 延迟是否可调、重复触发的一致性 | 漏报、方向与速度估算 |
| 告警保持与恢复条件 | 是否保持输出、保持多久、恢复后多久可再次检测 | 连续通行和重新就绪 |
| 双光束逻辑 | 是否同时遮挡才输出、是否只能读一路汇总信号 | 通道数量与人体触发位置 |
| 户外指标 | 明确的户外距离、光照条件、防护要求 | 能否扩展至目标场地 |
| 多对同时工作 | 是否有通道选择或其他抗串扰措施 | 平行双线、折角近邻安装 |

优先同型号两对，方便比较延迟和调试。无源干接点适合告警接入，但继电器不保证测速精度；数字 / 开集电极输出也不自动等于快速或兼容 ESP32。以说明书和测量为准。

如果探头只适合告警，首轮仍可做边界检测；速度显示标“未验证”，待评估响应误差或更换接口合适的快速探头后再启用。

## 4. 三种摆放方式

### 单线

使用一对探头跨过通道，另一对暂不参与。实现稳定的遮挡、恢复、布防 / 撤防和告警计数。

### 门口通行

两条平行检测线沿行进方向前后排列，测量垂直间距 d；试验可从约 0.8–1 m 间距开始，之后按现场和器件响应调整。

```text
门外 → 检测线 A → 已测间距 d → 检测线 B → 门内
```

同一设备记录两路遮挡边沿，确认先后顺序，使用 `v = d / |tB - tA|` 估算通过速度。先 A 后 B 为进入，反向为离开。该解释适用于主要垂直穿过两线的通行；斜穿结果只是垂直方向的平均速度分量。

事件处理要求：

- 上电先确认两路状态，不把已经遮挡的初始状态作为一次完整通行。
- 首次有效遮挡后等待另一条检测线，设置超时和有效间隔范围；具体值依据间距、目标通行速度与探头响应试定。
- 两路近乎同时触发、只触发一路、折返或无法判断是否同一人的事件，显示“不确定 / 未完成”，不强行输出速度。
- 本次事件结束、两路恢复并满足重新就绪条件后，再接受下一次完整通行；不能以告警保持时间代替原始边沿时间。
- 多人并行、紧跟或复杂折返可能无法仅靠两路输入识别。首轮验证限定单人依次通行，不宣称可靠的人数统计或异常通行识别。

### 折线

将两对改为相邻的两段直线，共同形成一个折角；拐角处可以放一个接收端与另一个发射端，分别调向。

两段独立记录遮挡 / 恢复并在终端显示对应段。折角、探头间距和光轴互扰需要验证。此模式不根据两段间的事件时间差测速。

以下是建议执行方法，当前没有测试结果。

| 项目 | 执行方法 | 记录内容 |
| --- | --- | --- |
| 电气确认 | 接入控制板前测供电和输出状态 | 接线图、输出电压 / 类型、负载情况 |

| 速度估算 | 记录两线设备时间，并用可辨认两次越线时刻的视频等独立方法对照 | 原始时间、估算值、参考方法与误差；只算出数值不算验证完成 |
| 折线定位 | 分别遮挡 A、B 及同时遮挡两段 | 对应段状态是否正确、多对是否串扰 |

| 连接与电源 | 断业务连接、重连及重启控制板 | 离线显示、状态恢复；触点本身无法提供的故障不伪报 |

单段稳定后再测组合；若组合失败，先定位响应、串扰、安装和配对问题。原始结果都写入同目录 VALIDATION.md，尚未测试时不预填成功。

## 8. 产品构造与外形方向

以下是供下一阶段讨论的建议，不是已经确定的尺寸或已经完成的工业设计。

### 建议的首轮结构

先使用两个发射端、两个接收端和一个控制盒。控制盒容纳开发板、稳压和输入接口，读取两段信号并与终端通信；每个探头是否与控制盒合并，按接口和体积再定。这个结构便于采购和排查问题，最终仍可缩小或集成。

成品对射头优先保留原光学窗口、遮光和密封结构，先验证功能；不要为了外观增加未经验证的红外透光罩，或拆掉现有密封。普通透明材料也不能直接假定适合所选红外波段。

### 外形草案

| 部位 | 建议形式 | 设计要点 |
| --- | --- | --- |
| 探头 | 小型圆角长方盒，能调整水平 / 俯仰角度 | 正面为光学窗口与对准 / 状态指示，具体开孔服从传感器结构 |
| 控制盒 | 独立的小型圆角盒 | 留电源、信号线接口和必要状态灯；告警内容仍在既有终端显示 |
| 安装背板 | 可拆底座或转接件 | 可配墙面底座、栏杆夹具或绑带；安装方式不绑定立柱 |
| 出线与接口 | 初步考虑侧下方或底部引出 | 为线缆固定、密封和维修留空间，具体方向需按摆放方式验证 |
| 可选附件 | 地插、三脚架或立柱 | 无现成固定物时再配置，不并入核心设备外壳 |

尺寸等探头、开发板、连接器和稳压模块确定后再画，不预设“掌心大小”即可容纳所有东西。初版可用成品盒和转接支架验证，不提前做定制外壳。
