# 相机测试模块（131）

通过桌面调试启动入口自动接入，确认权限后在主页打开“相机（测试）”。

- 开始：每 400 ms 请求一张 TCP 模拟画面，320×240 PNG 彩条及移动标记。
- 停止：停止自动刷新；采集单帧：取得一帧后保持。
- 拍照 / 保存 PNG：冻结点击时的画面，使用文件选择器保存。
- 最小化隐藏期间暂停画面请求，恢复可继续；切换销毁页面后不保留计时器。
- 模块断开：沿用原会话断开协议。

这是明确标注的模拟相机，不使用本机摄像头，也未实现 ESP32-CAM 驱动。
后续接真实硬件需要对接图像采集端及大帧传输协议。
