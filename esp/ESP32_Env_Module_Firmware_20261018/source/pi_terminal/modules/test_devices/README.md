# 两个桌面测试模块

通过桌面 `orange_pi_terminal` 启动图标，或在工程目录执行：

```bash
BUILD_DIR="$PWD/build-preset" bash scripts/run-desktop.sh
```

启动后，示例模块 128、环境监测 129、计数器 130 会通过 PBR1 伪串口依次接入。
按提示选择“仅本次”或“始终信任”，然后在主页打开对应模块。
直接运行裸二进制不会自动启动模拟服务。

## 环境监测（129）

- “开始”：采样一组模拟温湿度，采样序号递增；不是持续后台采样。
- “停止”：返回停止状态。
- “复位”：重置采样序号，显示初始模拟值。
- 页面曲线保存最近 40 次回包温度；“清除本页曲线”只清除页面历史。

## 计数器（130）

- “加一”“减一”“复位”：向独立 TCP 模拟设备发送命令，显示返回的计数。
- 每条连接拥有独立计数；断线重连会重置模拟设备状态。
- 页面记录最近 100 次返回结果；“清除本页记录”不重置设备计数。

两个模块都支持“模块断开”。最小化/恢复保留当前页面；切换到其他模块后
重新创建页面时，本页曲线/记录重新开始，设备会话保留。

## 实现及验证

复用示例插件的 C ABI 实现，各自编译为独立 .so、嵌入各自 manifest，
QML 页面在打包前准备，通过现有 Ed25519 签名和加载验证流程。
没有修改宿主签名、权限、架构和 ABI 验证代码。

原有 CTest 6/6 通过；三个不同 ID 的隔离 GUI 测试验证了逐页打开、
环境采样/停止/复位、计数加减/复位、会话模型绑定、最小化恢复和退出。
结果：`build-preset/new-modules-audit-results/`。
本机模拟通过不等同于 ESP32 固件或真实传感器验收。
