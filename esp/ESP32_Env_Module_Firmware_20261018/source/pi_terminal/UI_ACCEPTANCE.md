# Material 应用启动器与状态栏验收

## 参考与当前设计

应用页使用固定工作区，任务栏支持多个应用任务切换；不提供应用内部自由拖动或贴靠。应用表面自身支持最大化/最小化，Qt主窗口保持不变。浏览器支持地址跳转、前进/后退/刷新、链接导航及触摸滚动。

当前支持多个同时打开的应用任务记录：任务栏使用 `openTasks` 保存打开中的任务；切换任务不会关闭前一任务，关闭任务才从任务栏移除。业务会话和插件生命周期由 `ConnectionManager` 独立维护。

标题栏拖动区避开排列、最小化、关闭按钮，不会覆盖这些按钮。热点和蓝牙状态均以系统最终状态为准，操作失败会显示错误通知。

界面采用圆形应用图标、最近应用区、通知/网络/电源/时钟状态区；不依赖外部示例图片或固定数字。

当前界面保留深蓝色整体配色、Qt6/QML、GPU背景、自适应和原有字号/热区要求，交互改为手机式应用启动器。

### 主页

- 使用 **33 个 Google Material Icons Round SVG 图标**，本地打包，Apache-2.0许可。不是字符占位图标，也不是运行时联网下载。
- 大圆形图标＋名称，横向分页，按窗口宽高自动调整1–4列、1–2行；触屏滑动、点按和键盘方向键可用。
- 删除了“主页 / 模块 / 浏览器 / 文件 / 设置”的底部文字标签导航。
- 模块一接入就注册主页入口，显示准备状态；签名验证、权限确认和加载完成后，直接点该图标打开模块功能。
- 模块功能在独立应用页，不再嵌在“连接管理”内。连接管理只负责状态、重试和断开。
- 模块清单可使用 `icon` 指定内置Material图标名；未指定或未知时使用通用extension图标。加入新模块无需修改终端业务代码。

### 打开与关闭

- 点图标时，从图标所在位置展开：260ms缩放＋透明度动画。
- 关闭按钮或状态区的主页按钮：200ms缩回主页。
- 关闭应用页面不会断开模块连接；再次点击主页功能图标可以重新打开。停止采集操作仍由功能页的“停止”或“连接管理 → 断开”明确执行。
- 模块真正断开时先完成关闭动画，然后清空QML Loader，下一轮事件循环才释放插件。不会在缩放过程中提前卸载仍在显示的 `.so` 页面。
- 最近应用区只显示实际打开过的应用，最多3个；模块断开后清除相应失效入口。

### 淡模糊

- 背景继续使用4级FBO降采样链：1/2 → 1/4 → 1/8 → 1/16，再逐级上采样。
- 应用图标改用 **1级浅金字塔、strength=0.35、原图90%＋模糊10%** 的GPU混合；不再把整个功能入口重度糊掉。
- 图标名称和状态文字不参与模糊，保持清晰。保留很轻的Z轴倾斜，不再使用巨大的倾斜矩形卡片。
- 未使用 `QGraphicsBlurEffect`。

### 图片启发的状态区

底部是紧凑的系统状态区，而非功能标签栏：

- 左侧：回到应用主页。
- 中间：实际最近打开的应用图标（屏幕较窄时收起）。
- 右侧：未读通知、网络、蓝牙、电量/电源和实际系统时间。
- 点击状态或右上角的快捷设置图标，打开设备面板，查看连接、电池、内存、存储和内部通知，并进入连接管理/设置，操作TTS、蓝牙、预配置热点。

状态不是装饰数据：

| 信息 | 数据来源及边界 |
|---|---|
| 网络 | QNetworkInterface的运行状态与地址；表示接口连接，不宣称互联网探测成功 |
| 蓝牙 | QtBluetooth本地适配器及电源状态；没有适配器时禁用相应开关 |
| 电量 | Linux `/sys/class/power_supply` 中的系统电池；没有读数时明确显示未检测到系统电池 |
| 内存、存储 | `/proc/meminfo`、QStorageInfo |
| 通知 | 本应用真实的操作/连接日志事件，不是照片里的固定“6”；不声称接管整个桌面系统的通知 |
| 最近应用 | 本次运行实际打开记录，不伪造已运行程序 |

蓝牙和热点只有用户明确点击开关才发出操作，测试不修改当前网络或蓝牙电源状态。

## 可读性与响应式

- 正文至少18pt、标题至少24pt，主要热区64dp、控件间距至少16dp。
- 26组文字配色的最低对比度为6.081:1；图标保持深色字形与浅色圆形背景。
- 支持100% / 125% / 150%界面大小并保存偏好；大屏还自动适度放大。
- 窄屏不把整页缩成小字，改为减少列数、隐藏次要状态图标、按钮换行和纵向滚动。
- 被状态区收起的信息仍可在设备面板查看；名称过长时像参考图一样省略，应用标题与连接管理中可查看名称。

## 自动测试

运行：

```bash
bash scripts/test.sh
```

当前6个CTest测试组全部通过。UI测试在普通DPR和1.5倍DPR各检查54个布局状态：

- 1280×800、1280×720、1024×768、800×480、480×800、640×640、1920×720、1920×1080、360×640，各5个内置主页面。
- 150%界面大小的5个页面，以及权限、文件编辑、书签和设备状态面板。
- 检查真实控件尺寸、字号、状态区是否越界；确认大字倍率不会被定时状态刷新重置。
- 注入触屏横滑/点按/纵向滚动，验证缩放动画有中间帧、图标模糊比例不超过15%、Z轴方向正确。

端到端集成还验证：通过PTY控制桥接入模拟模块 → 主页出现模块功能图标 → 触屏点图标直接进入功能页 → 收到数据42 → 缩放关闭但会话保留 → 从主页重新打开 → 真正断开时动画完成后才卸载 → 浏览器验证。

已经在实际桌面运行同一代码，OpenGL renderer为本机AMD Radeon RX 7600M XT。实体触屏驱动/校准及香橙派GPU表现仍需上板验收。

## 手动运行

仓库根目录：

```bash
bash 启动香橙派桌面调试.sh
bash 启动香橙派桌面调试.sh --window-size 800x480
bash 启动香橙派桌面调试.sh --window-size 480x800
```

首次模块接入确认权限后，直接点主页“示例模块”图标；右上角关闭按钮会缩回主页。点底部状态区或右上角调节图标管理终端。

颜色计算覆盖内置界面，不是整个应用的WCAG认证；任意第三方网页、未来插件需分别遵守同样的字体/配色/响应式契约。
